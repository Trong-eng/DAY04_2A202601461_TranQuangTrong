# Product facts used for the UI reference

Checked on 2026-07-29 before implementing the Claude-inspired visual direction.

- Claude is an Anthropic assistant offered through web and mobile chat surfaces.
- Anthropic presents Claude as supporting research, web search, integrations, and code/content creation.
- Claude's official product page describes Artifacts as a way to create and iterate beside a conversation.

Official sources:

This project is not an Anthropic or Claude product. It uses a warm editorial chat layout as a visual reference only. It deliberately does not copy the Claude logo, product name, or proprietary assets.
